How the MedSynapse Interactive Assistant works

A visual guide for medical writers: how the pieces connect, how to make content, how to save your free usage, and how updates arrive.

1 How it connects2 Making content3 Save usage4 UpdatesComponent library

1. How the pieces connect

The assistant lives in a private GitHub repository. Claude copies it once (the plugin), and keeps it up to date. You work only in Claude and TinyMCE.

PieceWhat it is
GitHubThe online folder where the assistant and its component library are stored. Only invited people can open it.
PluginA copy of those files inside your Claude. You add it once; later you only check for updates.
medsyn-assetsA public folder holding the small animation files and the library page. Your published content loads animations from there.
TinyMCEThe editor on MedSynapse where you paste the finished HTML.

2. How a writer makes interactive content

Everything happens in one Claude chat. Open a new chat for each article.

Save your free usage: every question Claude has to ask costs a turn. Answer them all in your first message instead: see section 3.

3. Answer everything in your first message

Claude needs eight answers before it can plan your content. If you give them in the first message (together with your article), Claude skips the questions and the look picker, and goes straight to the plan. That is the cheapest way to work, especially on the free plan.

The questions, and what you can answer

#QuestionYour options
1FormatInteractive article (today's only format)
2AudienceHCP, or patient / caregiver
3PaletteA number from the picker (1-24), your own Coolors link or hex codes, or the client's brand colours
4LayoutA Classic, B Tinted, C Banded, D Clean, E Top rule, F Editorial, G Stepper
5Tap cue0 Plain, 1 Subtle, 2 Pulse chevron (recommended), 3 TAP chips (only if the client asks), 4 Ripple row, 5 Solid rows + white ripple, 6 Arrow trail
6Introduction, references, abbreviationsInclude or leave out each one. Default: leave the intro out; include references only if your source has them
7DensityConcise or fuller
8ImagesNone, or give the AWS link for each image. Without links, image data goes into components

Not sure what a palette, layout or tap cue looks like? Open the library page first (Palettes, layouts and tap cues), choose, then fill in the form below.

Build your first message


 

Paste it into a new Claude chat and attach your Word or PDF file. Claude then shows a plan table: check it and reply Looks good, go ahead (or tell it what to change). It will not build until you approve.



4. How an update reaches you


Claude only offers an update when the admin raises the version number. After an update, always start a new chat.
